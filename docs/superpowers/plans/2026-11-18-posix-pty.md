# POSIX pseudoterminal continuation

User scope: continue POSIX PTY support and test cancellation, resize and cleanup. This supersedes
the earlier utility plan's POSIX deferral. Keep existing Windows/redirected APIs and local changes.

Design: add `PosixPseudoTerminal(columns, rows)` using libc PTY allocation and `posix_spawn`
with a new session and child-side slave opening. No managed post-fork callback, helper executable,
runtime dependency or handwritten interface. Keep the bounded queue and existing session record.
Native child wait ownership reserves the child identity until owned-group cleanup and final reaping;
cancelled nonblocking I/O and locked resize/close must not act on a recycled descriptor or PID.

- [x] Test real tty/session identity, managed child-reaper coexistence, SIGWINCH, Ctrl+C, input,
  bounded output, individual write cancellation, stubborn children, resize/close races, failed
  startup descriptors, inherited-group descendants and exact reaping on actual Linux.
- [x] Update Utilities mode selection, protocol/platform documentation and CI native probe.
- [x] Independently review lifecycle/ABI handling; run rfs, isolated build/test and Windows
  regression/native checks. Preserve failed evidence and distinguish macOS source review from
  execution (no macOS runner is available locally).

Ruling: use a container init process for Linux tests. The .NET runtime may reap unknown native
children when running as PID one; reject that unsupported ownership configuration rather than
signal an identity that may have been recycled. Child processes deliberately escaping the owned
group are outside guaranteed group termination; terminal hangup and I/O cancellation still must
make transport shutdown finish.

Completion evidence is in VERIFICATION.md under POSIX PTY continuation. Linux x64 ran locally;
Linux ARM64/macOS x64 remain execution-unverified, and macOS ARM64 explicitly rejects PTY mode
pending a verified native variadic bridge. A real Linux inherited-slave deadlock was found and
fixed. Review hardening and the denied-signal fixture verified descriptor release and deferred
exact reaping when child credentials prevent group termination.
