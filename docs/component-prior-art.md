# Candidates for the default component set

The comparison below informed the default components. The library now ships task status indicators, keyed sortable tables, FIGlet banners, command bindings with help and a palette, single and multiple selectors, trees, collapsible sections and tabs. See the Tasks, Controls and Input / scroll pages in [Showcase](../examples/Showcase/README.md). Frozen columns and cell selection remain possible extensions to the row-oriented table.

| Priority | Component | What a Ranvier application would gain | Prior art |
| --- | --- | --- | --- |
| First | Activity indicator and task status | A spinner for an operation of unknown duration, a pulse for a bounded space, and static success, failure and cancellation states. A task row can combine these with a label, the existing meter, counts or elapsed time. Drive animation from the host clock and stop requesting updates when idle. | [Spectre.Console status](https://spectreconsole.net/console/live/status/), [Rich progress](https://rich.readthedocs.io/en/stable/progress.html), [Spectre.Console progress columns](https://spectreconsole.net/console/live/progress/) |
| First | Keyed data table | Extend the current virtual table with row identity and sortable headers. The process monitor could supply a PID as its row key and typed CPU and memory sort keys. Selection would follow the process across refreshes and heading activation would work by keyboard and mouse. Frozen columns and cell selection would be useful follow-ups for wider datasets. | [Textual DataTable](https://textual.textualize.io/widgets/data_table/) |
| Next | Shortcut help | Define each action's binding, caption and enabled state once. Render compact hints in a footer and expanded help in a popup from those same definitions. The monitor currently maintains its keyboard handling, footer hints and help text separately. | [Bubbles help and key bindings](https://github.com/charmbracelet/bubbles#help) |
| Next | Select, multi-select and command palette | Build on the anchored popup and virtual list. A select commits a stable option key, a multi-select maintains checked keys independently of the cursor, and a palette filters actions before invoking one. They share navigation, styling, placement and focus return. | [Textual widget gallery](https://textual.textualize.io/widget_gallery/), [Textual command palette](https://textual.textualize.io/guide/command_palette/) |
| Next | FIGlet text | A styled heading or splash can load a FIGfont once and render new text into a retained node. Bundle a compact font with explicit redistribution terms, allow caller-supplied fonts, and provide a plain-text fallback for narrow layouts. Compatibility tests should cover hardblanks, glyph endmarks, kerning and the font's specified overlap rules. | [Spectre.Console FigletText](https://spectreconsole.net/console/reference/api/), [FIGfont specification](https://github.com/cmatsuoka/figlet/blob/master/figfont.txt) |
| Later | Tree, collapsible section and tabs | Reusable navigation for hierarchical data and alternate views. A tree needs stable expansion state and keyboard navigation across visible nodes. A collapsible section is a smaller first application of the same interaction. | [Textual widget gallery](https://textual.textualize.io/widget_gallery/), [Ratatui Tabs](https://docs.rs/ratatui/latest/ratatui/widgets/struct.Tabs.html) |

The most useful combined showcase would be a task display: queued work gets a static indicator, discovery gets a spinner, a known total gets a meter, and completion gets a final status. A sortable table can show several tasks at once. Exercise narrow terminals, focus during refresh, and idle redraws alongside the visual examples.
